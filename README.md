# AstraEdu – AI Study Assistant

## SDG Goal

SDG 4 – Quality Education

## Project Overview

AstraEdu is an AI-powered Study Assistant developed using Botpress. The chatbot helps students improve learning outcomes through study planning, exam preparation, time management, goal setting, motivation, and learning strategies.

## Problem Statement

Many students struggle with effective study planning, productivity, and academic guidance. Lack of structured support often affects learning outcomes and academic performance.

## Proposed Solution

AstraEdu provides instant educational assistance through a conversational AI interface. It helps students manage studies, prepare for exams, set goals, and stay motivated.

## Features

* Study Planning
* Exam Preparation
* Time Management
* Goal Setting
* Motivation
* Learning Tips
* Fallback Response Handling
